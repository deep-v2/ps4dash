# ps4dash

Native PS4 (OpenOrbis) re-host of Geometry Dash 2.208's original x86-64 Windows binaries:
a PE loader + ms_abi shim layer (GL→Piglet, FMOD→sceAudioOut, input→DualShock 4).
No game files are included. You need your own copy of the game.

Status: early research. See [docs/PORTING_STRATEGY.md](docs/PORTING_STRATEGY.md).
Nothing here has been compiled or run on PS4 yet.
